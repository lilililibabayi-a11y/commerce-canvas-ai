# AI电商生图平台 Demo

一个用于面试展示的 React + Tailwind CSS 前端 Demo，定位为跨境电商卖家的 AI 生图提示词工作台。

## 功能

- 首页 SaaS 产品介绍
- 工作台页面
- 商品图片本地上传预览
- 商品名称、商品卖点、销售平台、图片风格表单
- 本地逻辑模拟生成提示词
- 输出三类结果：电商主图、场景广告图、TikTok封面图
- 一键复制提示词
- 生成历史记录
- 响应式适配桌面端和移动端

## 当前支持

- 销售平台：TikTok、Amazon、Shopee
- 图片风格：欧美简约、高级广告、科技感

## 运行方式

请先确认本机已安装 Node.js 和 npm。

```bash
npm install
npm run dev
```

启动后访问终端显示的本地地址，默认通常是：

```text
http://localhost:5173
```

## 构建

```bash
npm run build
npm run preview
```

## 技术栈

- React
- Vite
- Tailwind CSS
